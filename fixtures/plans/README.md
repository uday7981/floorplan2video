# fixtures/plans

Your five test floor plans go here (PNG / JPG / PDF / DXF) alongside an
`expected_plan.json` per fixture, used as a snapshot target by the M1 extract
tests. Keep each fixture under its own folder, e.g.:

```
fixtures/plans/
  house-01/
    source.pdf
    expected_plan.json
    notes.md
```

The system prompt mentioned fixtures already live here; this folder is
currently empty — drop your test files in before starting M1.
